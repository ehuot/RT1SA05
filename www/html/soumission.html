Deadline

For this project you will work in binomial constituted within the same TP group (possibly in trinomial if odd TP group, nobody is allowed to work alone).

You have until January 11th 2026 23:59 to submit your work on eCampus. Do not wait until the last minute. The server may crash, especially if it is saturated with your submissions.

At each submission, check that the upload has been done correctly by downloading your file and checking its integrity.

Archive

Your archive file in .tgz format (containing all your files to be submitted - see subject) must imperatively bear the family names (unaccented and without spaces) of the two students of the binomial in alphabetical order and use only one capital letter at the beginning of each family name. For example, for the binomial composed of Ayoub Mamri and Etienne Huot, the file will be called: HuotMamri.tgz. In case of a family name with spaces, for instance, if the binomial is composed of Amar Ramdane Cherif and Etienne Huot, the file name shall be called: HuotRamdanecherif.tgz.

Only the tar command (not a graphical program like TheUnarchiver, Winzip, xarchiver, etc) should be used to create it.

If your files are correctly placed in the directory ~etudiant/RT1SA05 you just will have to do:

etudiant@virtualdebian:~ cd
etudiant@virtualdebian:~ tar cfz HuotMamri.tgz RT1SA05

Upload your file on eCampus

The submission will be done on eCampus in the SAE prog_(RT1SA05) lecture space in the ad hoc section.

Only the first student, in alphabetical order, should submit the work of the binomial, i.e. the .tgz archive file.
